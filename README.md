# Gentrificació urbana a Barcelona

## Visualització interactiva i modelització predictiva de la gentrificació urbana: Anàlisi espacial dels barris de Barcelona

Aquest repositori conté el desenvolupament complet del Treball de Fi de Màster (TFM) centrat en l’anàlisi dels processos de gentrificació urbana a Barcelona mitjançant tècniques d’anàlisi geoespacial, ciència de dades urbanes i visualització interactiva.

El projecte combina dades obertes de caràcter socioeconòmic, residencial, demogràfic i turístic amb l’objectiu d’identificar patrons territorials de transformació urbana a través d’anàlisi espacial, construcció d’indicadors sintètics, tècniques de clustering i cartografia interactiva.

### Objectius del projecte

Els principals objectius de la investigació són:

 - Analitzar els patrons territorials de gentrificació a Barcelona
 - Construir un indicador sintètic de gentrificació
 - Explorar la relació entre pressió residencial i turistificació
 - Aplicar tècniques de clustering per identificar tipologies urbanes
 - Desenvolupar una plataforma interactiva de visualització geoespacial
 - Facilitar l’anàlisi urbana mitjançant dades obertes i anàlisi espacial

### Metodologia

El flux de treball del projecte s’estructura en diverses fases:
1. Recollida i integració de dades
2. Neteja i preprocessament de dades
3. Construcció d’indicadors sintètics
4. Anàlisi espacial i clustering territorial
5. Anàlisi exploratòria de factors socioeconòmics
6. Desenvolupament de visualització interactiva
7. Interpretació dels patrons urbans detectats

- clusters territorials,

- i patrons socioeconòmics als barris de Barcelona.

```Bash

```
